A few things to know

Will this create a new LCCT account?

No. The app uses the existing department websites. Each website controls registration, login and your records. It does not add shared automatic sign-in.

Is this a practice help desk?

No. The app connects to live websites. Any registration or support request goes to the real department. Do not submit fake tickets or sensitive information just to test the app.

Why does my device show an installation warning?

These are testing builds, not store-certified releases. Android permits APK installation only from sources you authorize. Windows packages are unsigned; Mac packages are unsigned and not notarized. School IT policies may block installation. Ask IT for help rather than disabling protection.

Does the desktop app keep the portal inside its own window?

The v0.2 desktop archives open your normal browser. The prepared v0.3 desktop upgrade adds an LCCT-owned portal window. Check the release notes for the version you download. A package being available does not mean it has passed testing on every device.

What about iPhone and iPad?

An APK cannot install on iOS. An Apple-signed release through TestFlight or the App Store is still needed. For now, use the portal in Safari. You can optionally use Safari’s Share menu to add the website to your Home Screen; this is a website shortcut, not an installed native app.

How do I report a problem?

Send the device model, operating-system version, app version and steps to reproduce to your project coordinator. Do not include passwords, counseling details or private student records. Open the project issue tracker for non-sensitive technical reports.
